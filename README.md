# BoardGamesHub

## Description

BoardGamesHub is an interactive web application built with React, designed for board game enthusiasts.
It allows users to explore and view board games, check their details, and, if authenticated, perform operations like adding, updating, or deleting games.

## Features

- **Game Browsing**: Explore a list of board games with detailed information about each.
- **Operations**: Authenticated users can add, update, or delete games.
- **Authentication**: Access advanced features by logging in.

## Technologies Used

- **Framework**: React
- **Database**: JSON (populated via API)
- **Styling**: Tailwind CSS for rapid and flexible design.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/robique50/BoardGamesHub.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BoardGamesHub
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the JSON server:
   ```bash
   npm run dev:server
   ```
5. In a new terminal, start the application:
   ```bash
   npm run dev
   ```

## Usage

- The application allows all users to browse and view games.
- Authenticated users have access to advanced features, such as adding new games, editing existing ones, and deleting them.
